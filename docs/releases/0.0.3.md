# VelCal 0.0.3

Standalone plus VST3 for Windows x64, Linux x64, and universal macOS; macOS also
includes an AU MIDI effect for Logic's MIDI FX slot.

## Changes

- Modernized shared standalone/plugin interface and new curve-editor app icon,
  with larger, sharper header artwork at full opacity.
- Paintbrush popup with 16 accent colours, remembered across restarts and shared
  by standalone and plugin editors without changing calibration profiles.
- Unboxed GitHub release-update status at the bottom left; taller default and
  minimum windows keep it clear of statistics and preserve curve-editor space.
- Smooth now applies to all keys together on the per-key tab and defaults to on.
  Automatic smoothing removes quantization kinks while remaining within one
  velocity step of calibration. Switching off restores the generated map;
  manual points, measurements and trims are retained. Global Smooth is separate.
- Saved profiles display filenames rather than internal MIDI/profile names.
  Menus stay inside the editor; unsaved profiles, empty libraries and missing
  files recalled from DAW projects are handled explicitly.
- Curve-point Input/Output readouts show complete numbers without ellipsis,
  including at graph edges.
- Expanded core, app and plugin regression coverage. Existing schema-4 profiles
  remain supported; legacy mixed per-key Smooth settings resolve to off for all
  keys when loaded.

VST3 is an instrument-style MIDI processor, not an audio insert. Route its MIDI
output into your piano. In Logic use AU in MIDI FX before the piano.
See [installation and routing](https://github.com/SH4DOWSIX/VelCal/blob/main/docs/INSTALLING.md).

Requirements: Windows x64; Linux x64 with glibc 2.35+ and compatible desktop/audio
libraries; macOS 11+ on Intel or Apple Silicon.

Windows/macOS installers are unsigned. macOS binaries are ad-hoc signed but not
Developer ID signed or notarized; security approval may be necessary and managed
Macs may block installation. No paid Apple developer account is used.

Only Windows has real keyboard/DAW validation, including Studio One correction
and project save/reopen. Linux/macOS remain experimental: automated checks do
not establish hardware/DAW compatibility. Real Logic testing is still needed.
The newest UI and smoothing changes still need a fresh hardware calibration
pass. An unfinished calibration capture is not saved in DAW state.
Installers preserve per-user profiles/preferences on uninstall and do not bundle
personal calibration data.
