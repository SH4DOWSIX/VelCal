# VelCal 0.0.1

First public early release of VelCal: per-key MIDI velocity calibration, guided
short-bar capture, editable per-key/global curves, profile saving, and MIDI routing.

## Testing Status

**Only Windows has been tested with a real keyboard and DAW.** Linux and macOS
packages are experimental: GitHub builds and core tests do not establish that
MIDI hardware, virtual ports, calibration, or DAW integration work on them.

If you encounter Linux or macOS issues, please
[create an issue on the repository](https://github.com/SH4DOWSIX/VelCal/issues/new).
Include your OS version, CPU architecture, MIDI device and DAW, the package you
downloaded, and steps to reproduce the problem. Windows issue reports are welcome too.

## Downloads And Setup

- **Windows x64 ZIP:** extract the whole folder into a writable location and run
  `VelCal.exe`. Create a virtual MIDI port with
  [loopMIDI](https://www.tobias-erichsen.de/software/loopmidi.html), keep it running,
  and select that port as VelCal's MIDI output and the DAW's MIDI input.
- **Linux x64 tar.gz:** extract the whole folder and run `./VelCal.AppImage`.
  Built on Ubuntu 22.04; requires a compatible glibc 2.35+ Linux desktop with X11
  or XWayland and ALSA MIDI support. This is not an ARM build.
- **macOS universal ZIP:** extract the whole folder to a writable location, such
  as a folder under your home directory, then open `VelCal.app`. Supports Intel
  and Apple Silicon; deployment target is macOS 11+. Keep `profiles/` beside the
  `.app` rather than placing it inside the bundle.

Profiles and app preferences stay in `profiles/` beside the executable, AppImage,
or macOS `.app`. No personal calibration data is bundled. Keep octave/transpose
settings on your keyboard unchanged between calibration and playing.

## Security Warnings

These builds have no trusted publisher signature. The macOS bundle has an
ad-hoc signature for Apple Silicon compatibility, but no Developer ID signature
or Apple notarization. Warnings or blocks are therefore possible.

Only proceed if you trust this repository and the downloaded file. The release
includes `SHA256SUMS.txt` to check download integrity; checksums are not a publisher
signature or a guarantee of safety.

### Windows

For a Microsoft Defender SmartScreen "Windows protected your PC" prompt, choose
**More info**, then **Run anyway** if that option is available and you trust the
download. Some policies, including Smart App Control or organization rules, may
block unsigned apps without an individual override. Do not disable antivirus or
system-wide protections to run VelCal; report the block if you cannot proceed.
See [Microsoft's SmartScreen guidance](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation).

### macOS

Attempt to open `VelCal.app` once. If blocked because its developer cannot be
verified, open **System Settings > Privacy & Security**, find the VelCal notice,
and choose **Open Anyway**, then confirm **Open**. The option may not be available
on managed Macs. Do not disable Gatekeeper globally or ignore a malware warning.
See [Apple's instructions](https://support.apple.com/en-gb/102445).

### Linux

If the AppImage is not executable, run `chmod +x ./VelCal.AppImage` in its extracted
folder, or enable "Allow executing file as program" in your file manager. If the
filesystem disallows execution, move the whole folder to a writable location
that permits it. Do not run VelCal as root.

If FUSE is unavailable, try `./VelCal.AppImage --appimage-extract-and-run`; this
uses temporary extraction instead of mounting. See the
[AppImage FUSE troubleshooting guide](https://docs.appimage.org/user-guide/troubleshooting/fuse.html).

## Known Limitations

- The keyboard display is fixed at 88 keys; MIDI processing supports all 128 notes.
- No undo/redo, unsaved-change warning, or section manager yet.
- An earlier stall involving a third-party Windows virtual MIDI endpoint has not
  been conclusively resolved. Queue and feedback-flood safeguards remain enabled.
- Please retain profile backups while trying this early release.
