# VelCal 0.0.5

Standalone and VST3 for Windows x64, Linux x64 and universal macOS. macOS also
includes an AU MIDI effect for Logic's MIDI FX slot.

## Changes

- **Standalone MIDI routing:** VelCal now uses existing MIDI outputs on every
  platform. Set up your own virtual connection using loopMIDI, macOS IAC or
  Linux ALSA MIDI Through.
- **Shareable global curves:** Custom presets save as individual
  `.velcal-curve.json` files. Import and Export let you share one curve without
  sharing your calibration profile. Existing shared presets gain individual
  copies automatically. Applied curves remain stored independently in profiles
  and DAW projects.
- **Played-key selection:** Playing a key selects it and scrolls it into view,
  including with standalone routing off. Releasing a key leaves it selected.
  Playing does not switch tabs or interrupt curve-point dragging.
- **Live velocity display:** Both graphs show the last strike with a cyan
  marker, guide lines and numeric velocities. The per-key graph shows keyboard
  input and corrected key velocity, including trim, with final MIDI velocity
  listed separately. The global graph shows the velocity entering the global
  curve and its final output. Values remain visible after release.
- **Improved calibration guide:** The popup has numbered instructions, a
  highlighted firm-press warning, scrolling content and fixed buttons. Guidance
  covers object length, consistent placement, overlapping sections, mechanical
  thumps and manual tuning when firm presses are uncomfortable.
- **Clearer expectations:** The popup and README explain what calibration
  improves and what it cannot do. It does not change physical feel or repair
  mechanical faults, and playing dynamics are preserved.

Existing schema-4 profiles and DAW project recall remain supported.

## Compatibility

Requirements: Windows x64; Linux x64 with glibc 2.35+ and compatible desktop/audio
libraries; macOS 11+ on Intel or Apple Silicon.

Windows/macOS installers are unsigned. macOS binaries are ad-hoc signed but not
Developer ID signed or notarized; security approval may be necessary and managed
Macs may block installation. No paid Apple developer account is used.

input/output and plugin loading were confirmed on Linux Mint and macOS for
0.0.4; broader calibration, DAW routing and project recall remain unverified
there.

The newest velocity displays and revised calibration popup still need hands-on
validation. An unfinished calibration capture is not saved in DAW state.

Installers preserve per-user profiles/preferences on uninstall and do not bundle
personal calibration data. Release assets include SHA256 checksums.
