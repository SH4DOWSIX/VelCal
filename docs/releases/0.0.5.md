# VelCal 0.0.5

Standalone plus VST3 for Windows x64, Linux x64, and universal macOS; macOS also
includes an AU MIDI effect for Logic's MIDI FX slot.

## Changes

- Standalone uses existing MIDI outputs on every platform. Configure your own
  virtual connection with loopMIDI, macOS IAC, or Linux ALSA MIDI Through;
  VelCal no longer offers an application-created virtual output.
- Custom global presets now also save as individual `.velcal-curve.json` files.
  Import and Export let you share one curve without sharing a calibration
  profile. Existing shared presets gain individual copies automatically.
  Applied curves remain independent copies in profiles and DAW projects.
- Playing a key selects it and scrolls it into view. Standalone listens to the
  selected input even with routing off. Releases and controllers do not change
  selection, and playing does not switch tabs or interrupt curve-point dragging.
- Both curve graphs show the last strike with a cyan marker, guide lines and
  velocity readout. Per-key input/output includes key correction and trim, with
  final MIDI velocity listed separately; global input/output shows the next
  stage. Values remain visible after release and are not rewritten by edits.
- The calibration popup has clearer numbered instructions, a highlighted
  firm-press warning, a scrolling body and fixed buttons. Guidance explains
  object length, consistent placement, overlapping sections, mechanical thumps,
  and manual per-key tuning when firm presses are uncomfortable.
- Popup and README explain what calibration can improve and its limitations:
  physical feel and mechanical faults are unchanged, and playing dynamics are
  preserved. Existing schema-4 profiles and DAW recall remain supported.

Requirements: Windows x64; Linux x64 with glibc 2.35+ and compatible desktop/audio
libraries; macOS 11+ on Intel or Apple Silicon.

Windows/macOS installers are unsigned. macOS binaries are ad-hoc signed but not
Developer ID signed or notarized; security approval may be necessary and managed
Macs may block installation. No paid Apple developer account is used.

## Testing Status

Windows has the most extensive real keyboard/DAW testing. The user reports the
initial routing, preset sharing and played-key changes appear to work locally.
The later velocity readouts and revised popup still need runtime validation.
Version 0.0.4 standalone MIDI input/output and plugin loading were confirmed on
Linux Mint and macOS; this is historical evidence, not validation of every 0.0.5
change. Broader Linux/macOS calibration, DAW routing and project recall remain
unverified. An unfinished calibration capture is not saved in DAW state.

Installers preserve per-user profiles/preferences on uninstall and do not bundle
personal calibration data. Automated build, test and installer verification for
0.0.5 is pending. Publish only after all three requested native jobs pass and
release artifacts/checksums have been verified.
