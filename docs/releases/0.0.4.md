# VelCal 0.0.4

Standalone plus VST3 for Windows x64, Linux x64, and universal macOS; macOS also
includes an AU MIDI effect for Logic's MIDI FX slot.

## Changes

- Plugin per-key/global tab selection now belongs to the DAW project or preset
  state, instead of a shared last-used preference. Standalone still remembers
  its last viewed tab.
- Profile actions and accent colour selection share a menu beside the profile
  selector. New, Open, Save, Save As, Reset All and Delete are grouped together.
  Save As creates a separate profile without overwriting the original.
- Unsaved profile transitions offer Save, Discard or Cancel, with confirmation
  for replacement and destructive actions.
- Clear Calibration removes calibration data while preserving the global curve
  and calibration settings. Reset All also resets the global curve and
  calibration settings; changes are not written to the profile until saved.
- Named global curve presets now persist immediately in a shared library,
  independently of saving a profile. Rename, Delete and replacement confirmation
  are supported. Existing profile-local presets remain accessible, and library
  edits do not change curves already stored in profiles or DAW projects.
- Compact profile and tab controls share one row, leaving more room for curves.
  Version/update status now sits above Global curve, using labels such as
  `v0.0.4` and `v0.0.4 - v0.0.5 is available`.
- Expanded profile, preset, dialog and DAW-state regression coverage. Existing
  schema-4 profiles remain supported.

VST3 is an instrument-style MIDI processor, not an audio insert. Route its MIDI
output into your piano. In Logic use AU in MIDI FX before the piano.
See [installation and routing](https://github.com/SH4DOWSIX/VelCal/blob/main/docs/INSTALLING.md).

Requirements: Windows x64; Linux x64 with glibc 2.35+ and compatible desktop/audio
libraries; macOS 11+ on Intel or Apple Silicon.

Windows/macOS installers are unsigned. macOS binaries are ad-hoc signed but not
Developer ID signed or notarized; security approval may be necessary and managed
Macs may block installation. No paid Apple developer account is used.

Only Windows has real keyboard/DAW validation, including Studio One correction
and project save/reopen. Linux/macOS remain experimental: automated checks do
not establish hardware/DAW compatibility. Real Logic testing is still needed.
The newest changes still need a fresh hardware calibration pass. An unfinished
calibration capture is not saved in DAW state.
Installers preserve per-user profiles/preferences on uninstall and do not bundle
personal calibration data.
