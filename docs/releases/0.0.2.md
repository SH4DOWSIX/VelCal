# VelCal 0.0.2

Standalone plus VST3 for Windows x64, Linux x64, and universal macOS; macOS also
includes an AU MIDI effect for Logic's MIDI FX slot.

- Full calibration and editing inside plugins; MIDI devices selected by the DAW.
- Profiles and edits embedded in DAW projects, with independent instances.
- Windows Setup EXE, Debian/Ubuntu package, Linux user-local installer, and macOS
  component-selectable PKG. Portable packages are no longer distributed.
- Writable per-user profiles/preferences, preserved on uninstall.

VST3 is an instrument-style MIDI processor, not an audio insert. Route its MIDI
output into your piano. In Logic use AU in MIDI FX before the piano.
See [installation and routing](https://github.com/SH4DOWSIX/VelCal/blob/main/docs/INSTALLING.md).

Requirements: Windows x64; Linux x64 with glibc 2.35+ and compatible desktop/audio
libraries; macOS 11+ on Intel or Apple Silicon.

Windows/macOS installers are unsigned. macOS binaries are ad-hoc signed but not
Developer ID signed or notarized; security approval may be necessary and managed
Macs may block installation. No paid Apple developer account is used.

Windows Studio One correction and project save/reopen are user-confirmed.
Linux/macOS remain experimental: native automated checks do not establish real
keyboard/DAW compatibility. Logic hardware testing is still needed.
An unfinished calibration capture is not saved in DAW state.

Automated release verification results are recorded in the project handoff.
